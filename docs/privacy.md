# Política de privacidad — EPEC Consumption Checker

*Última actualización: 13 de noviembre de 2026* · [English version below](#privacy-policy--epec-consumption-checker)

EPEC Consumption Checker es una extensión de Chrome que muestra tu consumo eléctrico diario de EPEC y, si lo activás, te envía un reporte o una alerta por email. **No está afiliada ni respaldada por EPEC.**

## Qué datos usa

- **Tu sesión de EPEC:** el token de acceso que la extensión obtiene cuando iniciás sesión en epec.com.ar. Ese token contiene, entre otros datos, tu email y tu número de documento.
- **Datos de tu cuenta:** nombre, apellido y email.
- **Tus contratos y consumos:** número de contrato y de cliente, titular, dirección y las lecturas diarias de consumo.
- **Tus preferencias:** días de reporte, límites de alerta y el contrato seleccionado.

## Para qué los usa

- Mostrarte tus consumos, el promedio y la proyección mensual en la extensión.
- Enviarte el reporte diario o la alerta de consumo **a tu propio email**, el registrado en tu cuenta de EPEC, solo si activaste esas opciones.

## Dónde se guardan

- **Solo en tu navegador** (almacenamiento local de la extensión). No hay base de datos en ningún servidor.
- Para enviar un email, la extensión manda al servidor de la extensión tu token de EPEC y el contenido del email. El servidor verifica el token con EPEC, envía el email a la dirección de ese token y **no guarda** ni el token ni el contenido.
- Los registros técnicos del servidor muestran la dirección de email parcialmente oculta (por ejemplo `fa*****@dominio.com`) y, si EPEC rechaza una sesión, un identificador cifrado del usuario, nunca el número de documento ni el token.

## Con quién se comparten

- **EPEC:** la extensión consulta la API de EPEC con tu sesión para obtener tus datos.
- **Google (Gmail):** se usa para enviar los emails.
- **Railway:** proveedor donde funciona el servidor que envía los emails.

No se venden ni se usan datos para publicidad, perfiles o analítica, y no se comparten con nadie más.

## Permisos de la extensión

- **storage:** guardar tus datos y preferencias en tu navegador.
- **Acceso a www.epec.com.ar:** leer la respuesta del inicio de sesión del sitio de EPEC para obtener tu sesión, y consultar tus contratos y consumos.

## Cómo borrar tus datos

Usá **"Salir"** en la extensión (borra todo lo guardado) o desinstalá la extensión.

## Uso limitado

El uso de la información obtenida cumple con la [Política de datos de usuario de Chrome Web Store](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq), incluidos los requisitos de uso limitado: los datos se usan solo para las funciones descritas arriba.

# Privacy policy — EPEC Consumption Checker

*Last updated: November 13, 2026*

EPEC Consumption Checker is a Chrome extension that shows your daily EPEC electricity consumption and, if you turn it on, sends you a report or an alert by email. **It is not affiliated with or endorsed by EPEC.**

## Data it uses

- **Your EPEC session:** the access token the extension obtains when you log in on epec.com.ar. The token contains, among other data, your email and national ID number.
- **Account data:** first name, last name and email.
- **Your contracts and consumption:** contract and customer numbers, holder name, address and daily consumption readings.
- **Your preferences:** report days, alert thresholds and the selected contract.

## What it uses the data for

- Showing your consumption, daily average and monthly projection in the extension.
- Sending the daily report or the consumption alert **to your own email**, the one registered in your EPEC account, only if you turned those options on.

## Where it is stored

- **Only in your browser** (the extension's local storage). There is no database on any server.
- To send an email, the extension sends your EPEC token and the email content to the extension's server. The server checks the token with EPEC, sends the email to that token's address and **does not store** the token or the content.
- The server's technical logs show the email address partly hidden (for example `fa*****@domain.com`) and, when EPEC rejects a session, an encrypted user identifier — never the ID number or the token.

## Who it is shared with

- **EPEC:** the extension calls EPEC's API with your session to get your data.
- **Google (Gmail):** used to send the emails.
- **Railway:** the provider that hosts the server that sends the emails.

Data is not sold or used for advertising, profiling or analytics, and is not shared with anyone else.

## Extension permissions

- **storage:** keep your data and preferences in your browser.
- **Access to www.epec.com.ar:** read the EPEC site's login response to obtain your session, and fetch your contracts and consumption.

## How to delete your data

Use **"Salir"** (log out) in the extension, which clears everything it stored, or uninstall the extension.

## Limited use

The use of information received complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq), including the Limited Use requirements: data is used only for the features described above.
